# Juno — Marketing & Docs

Make Accord Project's work visible and keep its documentation current.

## Objectives and KPIs

| Objective | KPI |
| --- | --- |
| Docs are current | Doc gaps found vs closed; docs PRs merged |
| Work is visible | Posts per release and per Tech WG; reach as reported by Matt |
| Drafts are ready to use | Share of drafts Matt approves with light or no edits |
